## Findings

### F01 — High: Storyboard export restores deleted speech

**Evidence:** `apps/web/server/storyboard-api.ts:199-215`;
`packages/storyboard/src/anchors.ts:21-28,67`;
`packages/storyboard/src/from-transcript.ts:38-49`.

The first storyboard excludes removed boundary words but keeps one continuous source range per segment.
Deleting a middle word does not split that range.
The exporter reads raw transcript anchors, not the frozen cut list.
Deleted speech therefore remains inside an exported talk scene.

**Fix direction:** Compile one edited timeline for playback, freeze, preview, and both export paths.
Represent disjoint source ranges explicitly.
Verify deletion with measured output audio, not only a completed job.
**Track:** `edit_timeline_integrity_20261122`.

### F02 — High: Reorder and silence change text without changing media correctly

**Evidence:** `packages/core/src/transcript.ts:175-204,289-322`;
`packages/media/src/cutlist.ts:107-147`;
`packages/core/src/sync.ts:11-34`.

Reorder changes word order while preserving source timestamps.
The cut-list builder ignores that order.
The playback lookup requires words sorted by source time.
Silence shifts source timestamps but neither inserts silent media nor preserves the original source mapping.

**Reproduction:** A direct Node probe moves `three` before `one drop`.
The exported kept range remains `[0,3]`.
Adding one second of silence also leaves `[0,3]`.
The probe imports the production TypeScript modules without changing them.

**Fix direction:** Keep source timestamps immutable.
Store output order and silence as explicit edits.
Add migration and undo tests.
**Track:** `edit_timeline_integrity_20261122`.

### F03 — High: Slide scenes restart speaker media and discard scene settings

**Evidence:** `apps/web/server/storyboard-api.ts:226-250,269-272`;
`packages/compose/src/assemble.ts:70-78`;
`packages/compose/src/render-step.ts:127-140,170-184`;
`packages/compose/src/composite.ts:64-75`.

Talk scenes carry source offsets. Slide and generated scenes do not.
Their speaker input starts at zero for every scene.
The export adapter also discards each scene's layer setting.
Valid `static` scenes and asset-backed `slide` scenes never enter the export plan.
A mixed storyboard can therefore export the wrong speech or silently omit scenes.

**Fix direction:** Carry source spans and layer settings through a shared scene compiler.
Reject unsupported or missing scenes before starting work.
Test every accepted visual kind and a scene that starts after zero.
**Track:** `edit_timeline_integrity_20261122`.

### F04 — High: A completed save can mark newer edits as saved

**Evidence:** `apps/web/pages/index.tsx:441-449`;
`apps/web/hooks/use-transcript-document.ts:177-182`;
`apps/web/hooks/use-auto-save.ts:65-91`.

The request captures one transcript. Its completion marks the current transcript as saved.
An edit during the request can therefore become clean without reaching disk.
Opening another project during that request can mark the new project's transcript as saved.
Switching projects also drops pending edits without a flush or confirmation.

**Fix direction:** Acknowledge the exact project and revision that the server saved.
Keep later edits dirty.
Flush or explicitly discard before switching projects.
Use delayed-response tests for both races.
**Track:** `save_export_integrity_20261122`.

### F05 — High: Export work can overwrite inputs and collide with another job

**Evidence:** `apps/web/server/storyboard-api.ts:178-185,258-261,305-307`;
`packages/compose/src/render-step.ts:89-92`;
`packages/compose/src/assemble.ts:105-119`;
`packages/media/src/export.ts:91-94,263-270`;
`apps/web/pages/index.tsx:1679-1685`.

Every storyboard job uses the same assembly directory and numbered segment files.
The Export button remains enabled during export.
Concurrent exports can replace each other's segments and concat list.
FFmpeg receives `-y` and the chosen final destination directly.
There is no source-alias check or explicit replacement confirmation.
The cut-list failure handler unlinks that destination, including a pre-existing file.

**Fix direction:** Use a job-specific directory and a temporary final output.
Reject source aliases, including symlinks and hard links.
Publish only verified output.
Require explicit replacement of existing output.
Preserve the previous file on failure or cancellation.
**Track:** `save_export_integrity_20261122`.

### F06 — High: Job cancellation does not stop export or transcription work

**Evidence:** `apps/web/pages/api/jobs/[id].ts:27-30`;
`apps/web/server/export-job.ts:18-29`;
`apps/web/server/transcribe-job.ts:27-35`;
`apps/web/server/storyboard-api.ts:285-307`;
`packages/ai/src/local.ts:123-131,160-161`.

The cancellation route reaches registered controllers.
Export creates an unregistered controller.
Transcription passes no signal to its provider.
Storyboard rendering and FFmpeg calls also receive no abort signal.
A job can show `cancelled` while processes continue and output changes.
Batch transcription has the same propagation gap.

**Fix direction:** Give every job one registered controller.
Propagate its signal through providers, rendering, and subprocesses.
Fence document writes after cancellation.
Test cancellation during a blocked operation, not only registry transitions.
**Track:** `job_lifecycle_20261122`.

### F07 — High: The local server lacks an explicit trust boundary

**Evidence:** `apps/web/package.json:7-10`;
`apps/web/vite.config.ts:5-12`;
`apps/web/server/http.ts:5-34`;
`apps/web/pages/api/projects.ts`;
`apps/web/pages/api/fs/list.ts`;
`apps/web/server/fs-api.ts:95-101`.

The application assumes a localhost-bound server.
Its production launch scripts expose all interfaces by default.
Installed vinext `1.4.6` sets `0.0.0.0` in `apps/web/node_modules/vinext/dist/cli.js:134`
and `apps/web/node_modules/vinext/dist/build/standalone.js:111`.
The lockfile pins that installed dependency.
The Vite configuration does not explicitly pin a loopback host.
The API has no application-level Host or Origin guard.
It exposes filesystem browsing, writes, capture, and paid generation.
Local-first operation does not make remote browser requests trustworthy.

This is a missing boundary, not a claim that all absolute paths are invalid.
Selecting arbitrary local source and destination folders is intentional.
The inspected production dependency confirms the broad listener default.
The build also emitted `apps/web/dist/standalone/server.js:6` with the same default.

**Fix direction:** Enforce loopback listeners for every supported start command.
Validate Host and Origin before API work.
Reject hostile browser origins and DNS-rebinding hosts.
Test the built server as well as development.
**Track:** `local_safety_20261122`.

### F08 — High: Asset identifiers can escape the generated-assets directory

**Evidence:** `packages/storyboard/src/parse.ts:55-57`;
`apps/web/server/storyboard-api.ts:237-244`;
`packages/compose/src/assets.ts:83-85`;
`packages/core/src/paths.ts:35-45`;
`packages/compose/src/brand.ts:134-136,149-154`.

Storyboard validation accepts any nonempty `assetId`.
Export joins it directly onto `assets/generated`.
A value such as `../../../outside.png` escapes that directory.
The general project resolver checks lexical containment only, not symlink targets.
Brand music also reaches FFmpeg without resolving its documented project-relative path.

**Fix direction:** Validate content hashes as identifiers.
Resolve project assets through one containment adapter.
Check real paths, including output parents and symlinks.
Resolve music against the project root.
Keep explicit external-media references separate.
**Track:** `local_safety_20261122`.

### F09 — Medium: Filtergraph safety relies on incomplete field validation

**Evidence:** `packages/compose/src/composite.ts:108-114,152-167`;
`packages/compose/src/assemble.ts:99-101`;
`apps/web/server/storyboard-api.ts:70-75`.

There is no dedicated filtergraph escaper.
The composite builder interpolates a caller-supplied color directly.
The dedicated waveform builder validates its color, but the composite builder does not.
A direct probe preserves `color=0x00FF00,negate` inside the filtergraph.
The current export route supplies an empty key, so this is not a proven remote exploit.
Geometry also lacks finite upper bounds and integer checks.
Concat-list escaping handles quotes but accepts line breaks.

**Fix direction:** Use a shared escaper for text fields.
Validate numeric and enum fields before serialization.
Reject line breaks in concat filenames.
Use Zod at the touched external boundaries.
**Track:** `local_safety_20261122`.

### F10 — Medium: Long work still runs inside requests, and components poll jobs

**Evidence:** `apps/web/server/image-api.ts:55-83`;
`apps/web/server/media-api.ts:51-69`;
`apps/web/server/waveform-api.ts:116-135`;
`apps/web/pages/index.tsx:711-724`.

Image generation holds its HTTP request until generation and persistence finish.
Media import holds the request during the full copy.
A waveform cache miss runs FFmpeg inside the request.
The page polls jobs every 500 milliseconds and stops after about five minutes.
It can stop observing a valid long export without reporting a timeout.
These paths contradict the job and event mandates.

**Fix direction:** Move slow operations into jobs.
Serve progress through job events and one client subscription.
Keep completed cached waveform reads cheap.
Test reconnects, project switches, and jobs longer than five minutes.
**Track:** `job_lifecycle_20261122`.

### F11 — Medium: Concurrent job persistence can write an older snapshot last

**Evidence:** `packages/core/src/jobs.ts:78-95,239-246,271-275`.

Each mutation saves the full job array.
The registry does not serialize those saves.
Atomic rename prevents partial JSON, but it does not preserve snapshot order.
Delayed writes from different jobs can replace newer state with older state.
The store also casts arbitrary JSON arrays to job records without validating entries.
Queued jobs survive restart without an owner or an explicit recovery decision.

**Fix direction:** Serialize registry mutations and persistence.
Validate stored records.
Reconcile both queued and running jobs deterministically.
Test reversed save completion with a reopened file store.
**Track:** `job_lifecycle_20261122`.

### F12 — Medium: Stream normalization does not cover silent or stereo sources

**Evidence:** `packages/compose/src/composite.ts:155-158,194-195`;
`packages/compose/src/video-range.ts:59-82`;
`packages/compose/src/assemble.ts:104-115`;
`packages/compose/src/render-step.integration.test.ts:39-66,134-139`.

Silent talk sources produce segments without audio, while brand bookends have mono audio.
Non-brand slide composites require `[1:a]`, which silent sources lack.
Stereo talk sources retain stereo audio beside mono bookends.
Fixing sample rate alone does not establish identical concat stream parameters.

**Fix direction:** Probe stream topology once.
Synthesize silence where necessary.
Normalize channels, sample rate, pixel format, geometry, and codec parameters.
Measure a mixed silent/stereo/slide export before concat-copy.
**Track:** `edit_timeline_integrity_20261122`.
