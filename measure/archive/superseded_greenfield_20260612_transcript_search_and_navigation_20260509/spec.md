# Track: Transcript Search and Navigation

## Problem
Long recordings (1+ hours, 5000+ words) make it difficult to find specific moments. Users need text search within transcripts with keyboard navigation.

## Goal
Add a search bar to the transcription view that finds words/phrases, highlights matches, and allows jumping between results with Ctrl+G / Ctrl+Shift+G.

## Acceptance Criteria
- [ ] Search bar in transcription view with real-time filtering
- [ ] Case-insensitive search across all words
- [ ] Highlight matches in VirtualizedWordContainer
- [ ] Jump to next/previous match with keyboard shortcuts
- [ ] Result count display (e.g., "3 of 12")
- [ ] Search clears on Escape
- [ ] Tests pass
- [ ] Build and vet clean
